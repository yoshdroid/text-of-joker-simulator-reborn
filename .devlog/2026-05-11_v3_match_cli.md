# 2026-05-11 v3 match CLI

## 実装内容

- `docs/implementation_spec_v3.md` を作成した。
- `tojs_reborn.io.decklist` を追加し、decklist JSON の読み込みと validation を実装した。
- `tojs_reborn.io.match_setup` を追加し、decklist から `GameState` を構築できるようにした。
- `MatchRunner.run_match` を追加し、複数 turn の match loop を実装した。
- `match_started` / `match_ended` event と、match 単位 replay intent を追加した。
- `tojs_reborn.io.match_cli` を追加し、sample player / external process player の 1 match 実行に対応した。
- `tojs_reborn.io.process_player` を追加し、JSON Lines 子プロセス player を起動できるようにした。
- `tojs_reborn.io.replay_cli` を追加し、保存 replay の検証 CLI を実装した。
- `JsonLinePlayer` の標準 timeout を 0.5 秒に変更した。
- timeout / invalid JSON / illegal action など、子プログラム通信 fallback の理由を `player_response_fallback` event に記録するようにした。

## v3 で本体実行できること

- decklist JSON を2つ指定して match を開始できる。
- `sample:first` / `sample:pass` を指定して in-process player の対戦を実行できる。
- `cmd:<command line>` を指定して外部子プロセス player の対戦を実行できる。
- replay JSON を保存できる。
- replay JSON を match CLI の `--verify-replay` または replay CLI で検証できる。

## 暫定仕様

- 初期 life は 7。
- 初期 hand は deck 上から 4 枚。
- `--p1` 側を先攻とする。
- 先攻 CP schedule は `2,3,4,5,6,7...`。
- 後攻 CP schedule は `3,3,4,5,6,7...`。
- 先攻初回 draw は 0 枚、それ以外の turn draw は 2 枚。
- `max_turns` 到達時は life が高い player の勝利、同点なら後攻 `P2` 勝利。
- decklist はデフォルトで小型テストデッキを許可する。
- `--strict-deck-rule` 指定時のみ 40 枚 / 同一カード3枚制限を検査する。
