# V4 Mulligan

## 実装内容

- `MatchRunner.run_match()` の試合開始後、最初のターン開始前に mulligan phase を追加した。
- プレイヤーごとに P1 -> P2 の順で確認し、各プレイヤー最大 5 回まで mulligan を選択できる。
- mulligan は現在の手札をデッキへ戻し、デッキをシャッフルして同じ枚数を引き直す。
- `mulligan_requested` / `mulligan_selected` / `deck_shuffled` / `mulligan_performed` をイベントとして記録する。
- replay intent に mulligan の選択と結果の手札・デッキ順を保存し、乱数状態に依存せず完全再実行できるようにした。
- JSON Lines 子プログラム向けに `request_mulligan` / `mulligan_selected` の runner 実装を追加した。
- sample player は現時点では常に mulligan しない。

## テスト

- `JsonLinePlayer` の mulligan 応答処理。
- state 付き mulligan request の private hand 表示。
- sample child program の mulligan 応答。
- `MatchRunner` の mulligan phase と replay 一致。
- 既存 engine / protocol テスト全体。
